# waktu-jemaah-prayer-reminder


**Mosque Congregation Prayer Reminder for Malaysian Communities**

![Flutter](https://img.shields.io/badge/Built%20with-Flutter-02569B?logo=flutter&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Android-3DDC84?logo=android&logoColor=white)

## Overview

Waktu Jemaah retrieves official prayer times from JAKIM e-Solat by zone and lets users add their mosque's congregation offsets, so reminders match when the congregation prays. It is designed for residents of condominiums and apartments in Malaysia.

## Features

- Prayer times by JAKIM e-Solat zone
- Per-prayer congregation offsets
- Local reminders
